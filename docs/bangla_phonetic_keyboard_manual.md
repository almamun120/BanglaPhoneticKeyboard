# বাংলা ফোনেটিক কিবোর্ড — টাইপিং ম্যানুয়াল

সব হরফ ছোট হাতের ধরেই টাইপ হয়। শিফট (⇧) চাপলে কী-র ইংরেজি হরফ শুধু বড় দেখায়, বাংলা টাইপিংয়ে কোনো প্রভাব ফেলে না। প্রতিটি নিয়ম পরীক্ষিত।

## ১. স্বর

| টাইপ | শব্দের শুরুতে / স্বরের পরে | ব্যঞ্জনের পরে (কার) |
|---|---|---|
| `o` | অ | (কিছু না, ব্যঞ্জন+অ) |
| `a` | আ | া |
| `i` | ই | ি |
| `ii` | ঈ | ী |
| `u` | উ | ু |
| `uu` | ঊ | ূ |
| `rrr` | ঋ | ৃ |
| `e` | এ | ে |
| `oi` | ঐ | ৈ |
| `oo` | ও | ো |
| `ou` | ঔ | ৌ |

`o` ব্যঞ্জনের পরে কিছু বসায় না, কিন্তু যুক্তাক্ষর ভাঙে: `kotha` = কথা (ক্থ নয়)। এই অবস্থায় লেখার মধ্যে একটি **লাল `o`** মার্কার দেখা যায়; পরের অক্ষর চাপলেই সেটি সরে যায়, শব্দ পাকা হলে থাকে না।

## ২. ব্যঞ্জন

| টাইপ | অক্ষর | টাইপ | অক্ষর | টাইপ | অক্ষর |
|---|---|---|---|---|---|
| `k` | ক | `kh` | খ | `g` | গ |
| `gh` | ঘ | `qng` | ঙ | `c` | চ |
| `ch` | ছ | `j` | জ | `jh` | ঝ |
| `qn` | ঞ | `tt` | ট | `tth` | ঠ |
| `dd` | ড | `ddh` | ঢ | `nn` | ণ |
| `t` | ত | `th` | থ | `d` | দ |
| `dh` | ধ | `n` | ন | `p` | প |
| `f / ph` | ফ | `b` | ব (শুধু স্বাধীন) | `bh / v` | ভ |
| `m` | ম | `y` | য় | `z` | য |
| `r` | র | `l` | ল | `s` | স |
| `ss` | শ | `sss` | ষ | `h` | হ |
| `x` | ক্ষ | `rr` | ড় | `rrh` | ঢ় |

- `r` = র, `rr` = ড়, `rrh` = ঢ়, `rrr` = ঋ/ৃ। তাই ড়ি/ড়ী সরাসরি লেখা যায়: বাড়ি = `barri`, ঘড়ি = `ghorri`, ঝড়ী = `jhorrii`। ঋ/ৃ: ঋষি = `rrrsssi`, কৃত = `krrrt`।
- `b` সবসময় আলাদা (স্বাধীন) ব দেয়, আগের অক্ষরের সাথে যুক্ত হয় না: `kb` = কব। যুক্ত ব (ব-ফলা) লিখতে `w` ব্যবহার করুন।
- `w` ব্যঞ্জনের পরে **ব-ফলা** (`sw` = স্ব, `dw` = দ্ব); শব্দের শুরুতে বা স্বরের পরে **ও** (`wjon` = ওজন)।
- ন/ণ-এর পরে `qn` ঞ নয়, শুধু ভাঙার চিহ্ন: `nqn` = ন্ন, `bhinqno` = ভিন্ন।

## ৪. `q` এর নিয়ম

`q` চাপলে লেখার মধ্যে একটি **সবুজ `q`** মার্কার দেখা যায় (পরের অক্ষর এলে সরে যায়), আর যেসব কী-র ফল `q`-এর কারণে বদলাচ্ছে তাদের ইঙ্গিত সবুজ হয়ে যায়।

- **ব্যঞ্জনের পরে `q`** = ভাঙার চিহ্ন (কিছু আসে না), যুক্তাক্ষর তবুও হয়। `utqtor` = উত্তর, `budqdhi` = বুদ্ধি, `bhinqno` = ভিন্ন, `tqth` = ত্থ।
- **স্বরের পরে/শুরুতে `q` + অক্ষর** = বিশেষ চিহ্ন: `qt` `qq` `qw`। `hotthaqt` = হঠাৎ, `caqqd` = চাঁদ।
- **স্বর ভাঙতে `q`**: `boqi` = বই (বৈ নয়), `koqoo` = কও, `koqi` = কই।
- `qn` = ঞ (ব্যঞ্জনের পরেও যুক্ত হয়): `poqnco` = পঞ্চ, `jqn` = জ্ঞ। `qng` = ঙ।
- `qr` = র, আগের ব্যঞ্জনের সাথে জোড়া ছাড়া: `dhqrm` = ধর্ম, `kqrm` = কর্ম।
- `rqz` = র‍্য (নিচের ৫ নম্বর দেখুন)।

## ৫. র-ফলা, রেফ, য-ফলা, ব-ফলা

- **র-ফলা**: ব্যঞ্জনের পরে সরাসরি `r`: `pr` = প্র, `kr` = ক্র, `str` = স্ত্র, `prem` = প্রেম।
- **রেফ**: শুরুতে বা স্বরের পরে `r` + ব্যঞ্জন নিজে থেকেই: `durga` = দুর্গা, `orth` = অর্থ। ব্যঞ্জনের পরে: `dhorm` = ধর্ম (`o` দিয়ে) বা `dhqrm`।
- **য-ফলা**: ব্যঞ্জনের পরে `z`: `kz` = ক্য, `bidza` = বিদ্যা, `sotz` = সত্য। `zz` = য্য।
- **র‍্য (র-এর সাথে য-ফলা)**: শব্দের শুরুতে `rz` → র‍্যাব = `rzab`। অন্য জায়গায় `rqz`। রেফ + য লিখতে সাধারণ `rz`: কার্য = `karz`, সূর্য = `suurz`।
- **স্বরবর্ণে য-ফলা**: অ-এর (বা যেকোনো স্বরবর্ণের) পরে `z` = য-ফলা: অ্যাপ = `ozap`। য-ফলা না চাইলে `q` দিয়ে ভাঙুন: অযথা = `oqzotha`।
- **ব-ফলা**: ব্যঞ্জনের পরে `w`: `sw` = স্ব, `dw` = দ্ব। অন্যত্র `w` = ও।

## ৬. কিবোর্ডের বাটন ও ইঙ্গিত

| বাটন | কাজ |
|---|---|
| `⇧` শিফট | শুধু কী-র ইংরেজি হরফ বড়/ছোট দেখায়। একবার চাপলে প্রথম অক্ষর পর্যন্ত, দুইবার চাপলে লক। বাংলা টাইপিংয়ে প্রভাব নেই |
| `o` (লাল কী) | যুক্তাক্ষরে বাধা; ব্যঞ্জনের পর চাপলে লাল `o` মার্কার দেখায় |
| `q` (সবুজ কী) | ভাঙার চিহ্ন; চাপলে সবুজ `q` মার্কার দেখায় |
| `,` | দুইবার = হসন্ত + ZWNJ |
| বাং / EN | বাংলা ও ইংরেজির মধ্যে বদল (চেপে ধরলে কিবোর্ড বদলানোর মেনু) |
| 😊 | ইমোজি প্যানেল (সাম্প্রতিক ইমোজি আগে) |
| ⌫ | চলমান শব্দের শেষ টাইপ করা কী একটি একটি করে মোছে |

**পরের-কী ইঙ্গিত:** শব্দ লেখার সময় প্রতিটি অক্ষর-কী-র গায়ে নীল ছোট লেখায় দেখায় ওই কী এরপর চাপলে কী আসবে। যেমন `k` চাপলে `h`-এ খ, `a`-তে কা, `r`-এ ক্র, `z`-তে ক্য, `w`-তে ক্ব। কার, ফলা, যুক্তাক্ষর, দুই-তিন অক্ষরের ব্যঞ্জন সব ক্ষেত্রেই এটি কাজ করে। `q` সক্রিয় থাকলে যেসব কী-র ফল `q`-এর কারণে বদলায় সেগুলোর ইঙ্গিত সবুজ। শব্দ শেষ হলে (স্পেস/চিহ্ন) ইঙ্গিত চলে যায়।

**২ সেকেন্ড চেপে ধরলে (এডিট কমান্ড):** নিচের কী-গুলো ২ সেকেন্ড চেপে ধরলে অক্ষরের বদলে কমান্ড চলে। ধরে রাখার সময় কী-র নিচে একটা লাইন ভরতে থাকে, আর প্রতিটি কী-র নিচের বাম কোণে ছোট করে কমান্ডের নাম লেখা আছে। ২ সেকেন্ডের আগে ছেড়ে দিলে সাধারণ অক্ষর বসে। চলমান বাংলা শব্দ আগে পাকা হয়, তারপর কমান্ড চলে।

| কী | কমান্ড |
|---|---|
| `x` | কাট (Cut) |
| `c` | কপি (Copy) |
| `v` | পেস্ট (Paste) |
| `z` | আনডু (আগের অবস্থায় ফেরা) |
| `y` | রিডু (আবার করা) |
| `a` | সব নির্বাচন (Select All) |

> আনডু/রিডু অ্যাপের নিজস্ব Ctrl+Z / Ctrl+Shift+Z শর্টকাট চালায়; যে অ্যাপ ওই শর্টকাট বোঝে না সেখানে কাজ নাও করতে পারে।

**কিবোর্ডের উচ্চতা:** অ্যাপ খুলে "কিবোর্ডের উচ্চতা" স্লাইডার দিয়ে ৭০% থেকে ১৫০% পর্যন্ত ঠিক করুন; পরের বার কিবোর্ড খুললে কাজ করবে।
