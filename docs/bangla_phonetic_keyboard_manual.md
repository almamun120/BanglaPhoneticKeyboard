# পপি কিবোর্ড — টাইপিং ম্যানুয়াল

সব হরফ ছোট হাতের ধরেই টাইপ হয়। শিফট (⇧) চাপলে কী-র ইংরেজি হরফ শুধু বড় দেখায়, বাংলা টাইপিংয়ে কোনো প্রভাব ফেলে না। প্রতিটি নিয়ম পরীক্ষিত।

## ১. স্বর

| টাইপ | শব্দের শুরুতে / স্বরের পরে | ব্যঞ্জনের পরে (কার) |
|---|---|---|
| `o` | অ | (কিছু না, ব্যঞ্জন+অ) |
| `a` | আ | া |
| `i` | ই | ি |
| `ii` | ঈ | ী |
| `u` | উ | ু |
| `uu` | ঊ | ূ |
| `rrr` / `qr` | ঋ | ৃ |
| `e` | এ | ে |
| `oi` | ঐ | ৈ |
| `oo` | ও | ো |
| `ou` | ঔ | ৌ |

`o` ব্যঞ্জনের পরে কিছু বসায় না, কিন্তু যুক্তাক্ষর ভাঙে: `kotha` = কথা (ক্থ নয়)। এই অবস্থায় লেখার মধ্যে একটি **লাল `o`** মার্কার দেখা যায়; পরের অক্ষর চাপলেই সেটি সরে যায়, শব্দ পাকা হলে থাকে না।

## ২. ব্যঞ্জন

| টাইপ | অক্ষর | টাইপ | অক্ষর | টাইপ | অক্ষর |
|---|---|---|---|---|---|
| `k` | ক | `kh` | খ | `g` | গ |
| `gh` | ঘ | `nng` | ঙ | `c` | চ |
| `ch` | ছ | `j` | জ | `jh` | ঝ |
| `nnn` | ঞ | `tt` | ট | `tth` | ঠ |
| `dd` | ড | `ddh` | ঢ | `nn` | ণ |
| `t` | ত | `th` | থ | `d` | দ |
| `dh` | ধ | `n` | ন | `p` | প |
| `f / ph` | ফ | `b` | ব (শুধু স্বাধীন) | `bh / v` | ভ |
| `m` | ম | `y` | য় (স্বাধীন) | `z` | য |
| `r` | র | `l` | ল | `s` | স |
| `ss` | শ | `sss` / `qs` | ষ | `h` | হ |
| `x` | ক্ষ | `rr` | ড় | `rrh` | ঢ় |

- `y` সবসময় স্বাধীন য় (আগে বা পরের ব্যঞ্জনের সাথে জোড়া লাগে না, `b`-এর মতো): `hoy` = হয়, `dey` = দেয়, `noy` = নয়। য-ফলা ও য-র জন্য `z`।
- `r` = র, `rr` = ড়, `rrh` = ঢ়, `rrr` বা `qr` = ঋ/ৃ। তাই ড়ি/ড়ী সরাসরি লেখা যায়: বাড়ি = `barri`, ঘড়ি = `ghorri`, ঝড়ী = `jhorrii`। ঋ/ৃ: ঋষি = `rrrsssi`, কৃত = `krrrt`।
- `b` সবসময় আলাদা (স্বাধীন) ব দেয়, আগের অক্ষরের সাথে যুক্ত হয় না: `kb` = কব। যুক্ত ব (ব-ফলা) লিখতে `w` ব্যবহার করুন।
- `w` ব্যঞ্জনের পরে **ব-ফলা** (`sw` = স্ব, `dw` = দ্ব); শব্দের শুরুতে বা স্বরের পরে **ও** (`wjon` = ওজন)।
- **ন-এর পরিবার**: `n` = ন, `nn` = ণ, `nnn` = ঞ, `nng` = ঙ, `ng` = ং। ন + ন (ন্ন) লিখতে মাঝে `q`: `nqn` = ন্ন, `bhinqno` = ভিন্ন। একইভাবে ণ্ন = `nnqn`, ণ্গ = `nnqg`।

## ৩. চিহ্ন

| টাইপ | ফল |
|---|---|
| `ng` | ং (শুধু `ng`-তেই) |
| `qn` / `nnn` | ঞ (দুটোতেই একই) |
| `qw` | ঃ |
| `qq` | ঁ |
| `qt` | ৎ (সব জায়গায়) |
| `qk` | ৳ |
| `.` | । |
| `0-9` | ০-৯ |
| `,,` | হসন্ত + ZWNJ |
| শুধু `q` | q-ই থাকে |

**ং:** শুধু `ng`-তে হয়: `bangla` = বাংলা, `songsar` = সংসার।

**ঞ:** `nnn` আর `qn` দুটোতেই ঞ হয় (যুক্তও হয়): `jnnn` = `jqn` = জ্ঞ। ব্যতিক্রম: ন/ণ-এর ঠিক পরে `qn` ভাঙার চিহ্ন + ন (ন্ন): `nqn` = ন্ন, `bhinqno` = ভিন্ন। ঙ লিখতে `nng` (`nngk` = ঙ্ক)।

**ঃ:** `qw` যেকোনো জায়গায় ঃ: `duqwkh` = দুঃখ, `monoqw` = মনঃ।

**ৎ:** `qt` স্বরের পরে, শব্দের শুরুতে এবং ব্যঞ্জনের পরেও ৎ দেয়: হঠাৎ = `hotthaqt`, জগৎ = `jogqt`, ভবিষ্যৎ = `bhobissszqt`। একমাত্র ব্যতিক্রম ত/ট-এর ঠিক পরে: সেখানে `q` ভাঙার চিহ্ন, তাই `tqt` = ত্ত, `utqtor` = উত্তর, `tqth` = ত্থ। তৎ লিখতে মাঝে `o` দিন: `toqt` = তৎ।

## ৪. `q` এর নিয়ম

`q` চাপলে লেখার মধ্যে একটি **সবুজ `q`** মার্কার দেখা যায় (পরের অক্ষর এলে সরে যায়), আর যেসব কী-র ফল `q`-এর কারণে বদলাচ্ছে তাদের ইঙ্গিত সবুজ হয়ে যায়।

- **ব্যঞ্জনের পরে `q`** = ভাঙার চিহ্ন (কিছু আসে না), যুক্তাক্ষর তবুও হয়। `utqtor` = উত্তর, `budqdhi` = বুদ্ধি, `bhinqno` = ভিন্ন, `tqth` = ত্থ। (ব্যতিক্রম: `qt` = ৎ, `qn` = ঞ, `qw` = ঃ ব্যঞ্জনের পরেও কাজ করে — ওপরের ৩ নম্বর দেখুন; ত/ট-এর পরে `qt` এবং ন/ণ-এর পরে `qn` ভাঙার চিহ্নই থাকে।)
- **স্বরের পরে/শুরুতে `q` + অক্ষর** = বিশেষ চিহ্ন: `qt` `qn` `qq` `qw`। `hotthaqt` = হঠাৎ, `bangla` = বাংলা, `caqqd` = চাঁদ।
- **স্বাধীন বর্ণ (ব্যঞ্জনের পরেও, আগের অক্ষরের সাথে না জুড়ে):**

  | টাইপ | ফল | উদাহরণ |
  |---|---|---|
  | `qo` `qoo` `qoi` `qou` | অ ও ঐ ঔ | `kqo` = কঅ, `kqoo` = কও |
  | `qa` `qi` `qii` `qu` `quu` `qe` | আ ই ঈ উ ঊ এ | `kqa` = কআ, `kqi` = কই |
  | `qz` | য (য-ফলা নয়) | `kqz` = কয |
  | `qh` | হ | `kqh` = কহ |
  | `qs` | ষ | `koqsa` = কষা (স/শ-এর পরে নয়: `sqs` = স্স) |
  | `qr` | ঋ (ব্যঞ্জনের পরে ৃ) | `qrsssi` = ঋষি, `kqrsssnn` = কৃষ্ণ |
  | `qx` | ক্স | `kqx` = কক্স |
  | `qt` | ৎ | `jogqt` = জগৎ |
  | `qq` | ঁ | `cqqa` = চঁআ (মাঝে `o` লাগে না) |
  | `qw` | ঃ | |
  | `qn` | ঞ | `jqn` = জ্ঞ |
  | `q.` / `q,` | ? / ! | `kq.` = ক? |

  ব্যতিক্রম: র-এর ঠিক পরে `qz` = র‍্য (`rqz`); স/শ-এর ঠিক পরে `qs` ভাঙার চিহ্ন (`sqs` = স্স); ত/ট-এর পরে `qt` ও ন/ণ-এর পরে `qn` ভাঙার চিহ্ন (`tqt` = ত্ত, `nqn` = ন্ন)।
- **একসাথে বহু `q`:** পরপর সর্বোচ্চ ২টি `q` বসে (`qq` = ঁ); তৃতীয় `q` চাপলে কিছু যোগ হয় না। ব্যাকস্পেস অদৃশ্য অক্ষর টপকে দৃশ্যমান পরিবর্তন পর্যন্ত একবারেই মোছে।
- **স্বর ভাঙতে `q`**: `boqi` = বই (বৈ নয়), `koqoo` = কও, `koqi` = কই।
- ঞ = `nnn`, ঙ = `nng` — এগুলোতে `q` লাগে না, ব্যঞ্জনের পরেও যুক্ত হয়: `ponnnco` = পঞ্চ, `jnnn` = জ্ঞ, `onngko` = অঙ্ক।
- **`qr` = ঋ বা ঋ-কার, যেখানে যেটা বসে:** শুরুতে/স্বরের পরে ঋ (`qrsssi` = ঋষি), ব্যঞ্জনের পরে ৃ (`kqr` = কৃ, `mqrtzu` = মৃত্যু)। `rrr` আগের মতো একই কাজ করে। ব্যতিক্রম: র-এর ঠিক পরে `q` ভাঙার চিহ্ন, তাই `rqr` = র্র। আগের "জোড়া ছাড়া র" লিখতে `o` দিন: `dhorm` = ধর্ম, `kormo` = কর্ম।
- `rqz` = র‍্য (নিচের ৫ নম্বর দেখুন)।

### দ্বিত্ব বর্ণ (একই বর্ণ পরপর) ও `q`

একই ব্যঞ্জন পরপর টাইপ করলে বেশির ভাগ সময় সরাসরি দ্বিত্ব হয় (`kk` = ক্ক)। কিন্তু যে বর্ণ দুইবার চাপলে অন্য একটি বর্ণ তৈরি হয়ে যায়, সেখানে মাঝে `q` দিয়ে ভেঙে দিতে হয়। `q` কিছু বসায় না, শুধু দুই অক্ষরকে আলাদা রেখে যুক্ত করে।

**`q` লাগে:**

| দ্বিত্ব | টাইপ | `q` ছাড়া লিখলে যা হয় |
|---|---|---|
| ত্ত | `tqt` | `tt` = ট |
| দ্দ | `dqd` | `dd` = ড |
| ন্ন | `nqn` | `nn` = ণ |
| স্স | `sqs` | `ss` = শ |
| শ্শ | `ssqss` | `ssss` = ষ্স |
| ণ্ণ | `nnqnn` | `nnnn` = ঞ্ন |
| র্র | `rqr` | `rr` = ড় |

উদাহরণ: উত্তর `utqtor`, সত্তা `sotqta`, হিস্সা `hisqsa`, উদ্দেশ্য `udqdessz`, র্র `rqr`।

**`q` লাগে না (সরাসরি দ্বিত্ব):** ক্ক `kk` · খ্খ `khkh` · গ্গ `gg` · ঘ্ঘ `ghgh` · চ্চ `cc` · ছ্ছ `chch` · জ্জ `jj` · ঝ্ঝ `jhjh` · ট্ট `tttt` · ঠ্ঠ `tthtth` · ড্ড `dddd` · থ্থ `thth` · ধ্ধ `dhdh` · প্প `pp` · ফ্ফ `ff` · ভ্ভ `bhbh` · ম্ম `mm` · য্য `zz` · ল্ল `ll` · ষ্ষ `ssssss` · হ্হ `hh`। ট্ট, ড্ড, ষ্ষ-তে চাইলে `q`-ও দিতে পারেন (`ttqtt`, `ddqdd`, `sssqsss`), ফল একই।

**ব্ব:** `b` আগের অক্ষরের সাথে যুক্ত হয় না, তাই ব্ব লিখতে `bw` (ব-ফলা)।

## ৫. র-ফলা, রেফ, য-ফলা, ব-ফলা

- **র-ফলা**: ব্যঞ্জনের পরে সরাসরি `r`: `pr` = প্র, `kr` = ক্র, `str` = স্ত্র, `prem` = প্রেম।
- **রেফ**: শুরুতে বা স্বরের পরে `r` + ব্যঞ্জন নিজে থেকেই: `durga` = দুর্গা, `orth` = অর্থ। ব্যঞ্জনের পরে: `dhorm` = ধর্ম (`o` দিয়ে) বা `dhqrm`।
- **য-ফলা**: ব্যঞ্জনের পরে `z`: `kz` = ক্য, `bidza` = বিদ্যা, `sotz` = সত্য। `zz` = য্য।
- **র‍্য (র-এর সাথে য-ফলা)**: শব্দের শুরুতে `rz` → র‍্যাব = `rzab`। অন্য জায়গায় `rqz`। রেফ + য লিখতে সাধারণ `rz`: কার্য = `karz`, সূর্য = `suurz`।
- **স্বরবর্ণে য-ফলা**: অ-এর (বা যেকোনো স্বরবর্ণের) পরে `z` = য-ফলা: অ্যাপ = `ozap`। য-ফলা না চাইলে `q` দিয়ে ভাঙুন: অযথা = `oqzotha`।
- **ব-ফলা**: ব্যঞ্জনের পরে `w`: `sw` = স্ব, `dw` = দ্ব। অন্যত্র `w` = ও।

## ৬. কিবোর্ডের বাটন ও ইঙ্গিত

| বাটন | কাজ |
|---|---|
| `⇧` শিফট | শুধু কী-র ইংরেজি হরফ বড়/ছোট দেখায়। একবার চাপলে প্রথম অক্ষর পর্যন্ত, দুইবার চাপলে লক। বাংলা টাইপিংয়ে প্রভাব নেই |
| `o` (লাল কী) | যুক্তাক্ষরে বাধা; ব্যঞ্জনের পর চাপলে লাল `o` মার্কার দেখায় |
| `q` (সবুজ কী) | ভাঙার চিহ্ন; চাপলে সবুজ `q` মার্কার দেখায় |
| `,` | দুইবার = হসন্ত + ZWNJ |
| বাং / EN | বাংলা ও ইংরেজির মধ্যে বদল (চেপে ধরলে কিবোর্ড বদলানোর মেনু) |
| 😊 | ইমোজি প্যানেল (সাম্প্রতিক ইমোজি আগে) |
| ⌫ | চলমান শব্দের শেষ টাইপ করা কী একটি একটি করে মোছে |

**পরের-কী ইঙ্গিত:** শব্দ লেখার সময় প্রতিটি অক্ষর-কী-র গায়ে নীল ছোট লেখায় দেখায় ওই কী এরপর চাপলে কী আসবে। যেমন `k` চাপলে `h`-এ খ, `a`-তে কা, `r`-এ ক্র, `z`-তে ক্য, `w`-তে ক্ব। কার, ফলা, যুক্তাক্ষর, দুই-তিন অক্ষরের ব্যঞ্জন সব ক্ষেত্রেই এটি কাজ করে। `q` সক্রিয় থাকলে যেসব কী-র ফল `q`-এর কারণে বদলায় সেগুলোর ইঙ্গিত সবুজ। শব্দ শেষ হলে (স্পেস/চিহ্ন) ইঙ্গিত চলে যায়।

**২ সেকেন্ড চেপে ধরলে (এডিট কমান্ড):** নিচের কী-গুলো ২ সেকেন্ড চেপে ধরলে অক্ষরের বদলে কমান্ড চলে। ধরে রাখার সময় কী-র নিচে একটা লাইন ভরতে থাকে, আর প্রতিটি কী-র নিচের বাম কোণে ছোট করে কমান্ডের নাম লেখা আছে। ২ সেকেন্ডের আগে ছেড়ে দিলে সাধারণ অক্ষর বসে। চলমান বাংলা শব্দ আগে পাকা হয়, তারপর কমান্ড চলে।

| কী | কমান্ড |
|---|---|
| `x` | কাট (Cut) |
| `c` | কপি (Copy) |

**কী চাপার শব্দ ও ভাইব্রেশন:** অ্যাপ খুলে "কী চাপার শব্দ" ও "ভাইব্রেশন" অংশে আলাদা আলাদা চালু/বন্ধ সুইচ আর ১%–১০০% মাত্রার স্লাইডার আছে। স্লাইডার ছাড়লে নমুনা শব্দ/কম্পন পাওয়া যায়; পরিবর্তন সঙ্গে সঙ্গে কাজ করে।

- শব্দ কী-র ধরন অনুযায়ী আলাদা: সাধারণ কী, স্পেস, মোছা (⌫), এন্টার। মোছা চেপে ধরে রাখলে প্রতিবার মোছার সাথে শব্দ হয়।
- ফোন সাইলেন্ট বা ভাইব্রেট মোডে থাকলে শব্দ বাজে না (ভাইব্রেশন সুইচ আলাদা)।
- ২ সেকেন্ড চেপে ধরার কমান্ড (কাট/কপি ইত্যাদি) পূর্ণ হলে কম্পন দ্বিগুণ হয়।
- মাত্রা: যে ফোনে কম্পনের জোর নিয়ন্ত্রণ করা যায় সেখানে জোর বদলায়; অন্য ফোনে কম্পনের সময় বদলায়।

**কিবোর্ডের উচ্চতা:** অ্যাপ খুলে "কিবোর্ডের উচ্চতা" স্লাইডার দিয়ে ৭০% থেকে ১৫০% পর্যন্ত ঠিক করুন; পরের বার কিবোর্ড খুললে কাজ করবে।
